      What it translates, what it refuses
      
      
      
        
      
          
      + Translates
      
          
        
            
      • SELECT with expressions and aliases, WHERE (with SQL NULL logic)
        • 
            
      • JOIN: INNER, LEFT, RIGHT, FULL, CROSS, SEMI, ANTI, USING
        • 
            
      • WHERE EXISTS / NOT EXISTS / IN (subquery) as semi and anti joins
        • 
            
      • GROUP BY with aggregates, HAVING, FILTER
        • 
            
      • ORDER BY (NULLS FIRST/LAST), DISTINCT, LIMIT, OFFSET
        • 
            
      • CTEs (WITH … AS), one named step chain per CTE
        • 
            
      • UNION, UNION ALL, INTERSECT, EXCEPT
        • 
            
      • Window functions and QUALIFY: ROW_NUMBER, RANK, DENSE_RANK, PERCENT_RANK, CUME_DIST, NTILE, LAG, LEAD, FIRST/LAST/NTH_VALUE, and SUM/COUNT/AVG/MIN/MAX over partitions, running totals and ROWS frames, spelled out as sort, index, group and merge steps
        • 
          
      
        
      
        
      
          
      − Refuses
      
          
        
            
      • RANGE/GROUPS frames with offsets, IGNORE NULLS, EXCLUDE, and DISTINCT or FILTER inside window aggregates.
        • 
            
      • Recursive CTEs, ROLLUP/CUBE/GROUPING SETS, NOT IN (subquery), scalar subqueries, LATERAL/ASOF/POSITIONAL joins, INTERSECT/EXCEPT ALL, DISTINCT ON.
        • 
            
      • LIKE patterns with _ or a % in the middle.
        • 
            
      • DAX is out of scope.
        • 
            
      • pandas input is out of scope.
        • 
          
      
        
      
        
      
          
      ! Keep in mind
      
          
        
            
      • SQL → M is not a round-trip identity. SQL results are unordered sets unless ORDER BY says otherwise; M tables are ordered lists of rows.
        • 
            
      • Power Query joins match rows whose keys are both null; SQL joins never match NULL keys. sql2m adds the filtering that makes the M join behave like the SQL one.
        • 
            
      • When window rows tie on ORDER BY, SQL leaves their order undefined; the M breaks ties by input order and sql2m warns you.
        •
